# 🏆 SPA Mundial 2026

## 📝 Descripción del Proyecto
Esta es una Single Page Application (SPA) interactiva desarrollada como proyecto para la asignatura de Programación Multimedia. La aplicación ofrece una experiencia fluida e informativa sobre la Copa Mundial de la FIFA 2026, destacando las sedes, el formato del torneo y la distribución de grupos.

El proyecto fue construido aplicando las mejores prácticas de desarrollo web, enfocándose en la separación de responsabilidades (archivos independientes para estructura, diseño y lógica), el uso estricto de etiquetas HTML5 semánticas y una arquitectura de diseño responsivo bajo el enfoque "Mobile First".

### ✨ Características Principales
* **Navegación SPA:** Transiciones entre las distintas secciones (Inicio, Sedes, Grupos, Contacto) sin recargar el navegador, gestionadas enteramente mediante la manipulación del DOM.
* **Diseño Responsivo:** Layout adaptable a dispositivos móviles, tablets y pantallas de escritorio utilizando CSS moderno (Flexbox y CSS Grid).
* **Interactividad (Hipermedios):** Elementos de información dinámicos que se despliegan u ocultan a petición del usuario mediante el uso de *Event Listeners* y alteración de clases.
* **Código Nativo:** Construido 100% con Vanilla JS, sin dependencias de frameworks externos, garantizando un rendimiento óptimo y carga inmediata.

## 🚀 Instrucciones de Ejecución

Dado que este proyecto está construido con tecnologías web base, no requiere de la instalación de dependencias (como Node.js o npm) ni de la configuración de servidores de *backend*.

### Opción 1: Ejecución Local (Método Directo)
1. Descarga o clona la carpeta de este proyecto en tu computadora.
2. Asegúrate de que los archivos `index.html`, `estilos.css` y `app.js` estén en la misma ruta.
3. Haz doble clic sobre el archivo `index.html`.
4. El proyecto se abrirá y ejecutará automáticamente en tu navegador web predeterminado (Google Chrome, Firefox, Edge, etc.).

### Opción 2: Ejecución para Entorno de Desarrollo (Recomendada)
Si deseas explorar el código y ver cambios en tiempo real usando Visual Studio Code:
1. Abre la carpeta del proyecto en VS Code.
2. Ve a la pestaña de extensiones e instala **Live Server** (si aún no lo tienes).
3. Haz clic derecho sobre el archivo `index.html` y selecciona la opción `"Open with Live Server"`.
4. El proyecto se abrirá en un puerto local (usualmente `http://127.0.0.1:5500`) y cualquier cambio que guardes en el código se reflejará automáticamente en el navegador.
